# Сайты учеников в интернете — короткий дизайн

Дата: 2026-11-25. Статус: на согласовании.

## Зачем
Ученики собрали HTML-страницы в своей песочнице. Их нужно открыть из любого браузера (телефон, родители, друзья)
по постоянному адресу ученика.

## Решено с преподавателем
- Адрес — путь на основном домене: `https://edu.qfenek.com/s/<логин>/` (например `/s/nikitoss/`). Без поддоменов
  и без DNS.
- Вариант «живая папка»: сайт отдаётся прямо из папки ученика, сохранил файл — обновил страницу — видно сразу.
  Папку выбирает преподаватель в карточке ученика, есть переключатель «Опубликован».

## Подходы (рассмотрены)
1. **Живая папка, выбирает преподаватель — выбран.** Ученикам ничего делать не нужно, задания и проверки
   (`~/site-maket`, `~/site`) не трогаем, выключается одним переключателем. Цена — виден и недоделанный вариант.
2. Одна папка для всех (`~/www`) — пришлось бы переписывать задания или держать файлы в двух местах.
3. Кнопка «Опубликовать» со снимком — ученики забывают нажимать, лишние копии на диске.

## Как устроено
- **Где файлы.** Дома учеников на сервере — `/srv/trainer/homes/seat<N>/student/` (диск места ученика). Этот
  каталог монтируется в контейнер API **только для чтения** (`TRAINER_HOMES_DIR`, в dev/тестах — любая папка).
  Работает и когда песочница ученика остановлена.
- **Настройка.** У ученика в группе два новых поля (миграция 0006, `group_students`): `site_dir` (путь внутри
  `/home/student`, по умолчанию пусто) и `site_published` (по умолчанию выключено).
  В «Группа → ученик» — блок «Сайт»: поле папки (если пусто — подсказка: первая папка с `index.html` на глубине
  до 2), переключатель «Опубликован», ссылка «Открыть» и «Копировать адрес».
- **Ученик** видит у себя строку «Твой сайт: https://edu.qfenek.com/s/<логин>/», когда сайт опубликован.
- **Отдача.** `GET /s/<логин>/<путь>` — без входа, в API; Caddy пропускает `/s/*` в API. Логин без учёта
  регистра. Не опубликован / нет папки / нет файла — простая страница 404 «Сайт ещё не опубликован».
  Каталог → его `index.html`; списка файлов нет.

## Безопасность (обязательно)
- Только статика, типы по расширению из белого списка (html, css, js, svg, картинки, шрифты, txt, json);
  остальное — 404. Файл больше 5 МБ — 404.
- Путь после разрешения ярлыков (realpath) обязан остаться внутри папки сайта: ярлык на чужое место, `..`,
  скрытые файлы и папки (`.ssh`, `.bash_history`) — 404.
- Страницы учеников живут на том же домене, что и панель, поэтому каждый ответ идёт с
  `Content-Security-Policy: sandbox allow-scripts allow-forms allow-popups allow-modals` и
  `X-Content-Type-Options: nosniff`: страница получает «чужое» происхождение, cookie сессии преподавателя ей
  недоступна и вызвать `/api` от его имени она не может (cookie `SameSite=Strict`, WebSocket проверяет Origin).
- `Cache-Control: no-cache` — чтобы правки были видны сразу.

## Не делаем
Поддомены и свои домены, серверный код (PHP, Python), загрузку файлов через сайт, статистику посещений,
снимки и историю версий.

## На усмотрение исполнителя
Вид блока «Сайт» в панели, текст страницы 404, точный список расширений.

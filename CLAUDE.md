## Что это
Удалённый учебный центр для подростков 13+: у каждого ученика своя комната с агентами LLM, свой Docker-контейнер
с терминалом в браузере и бэклог индивидуальных заданий. Преподаватель описывает уроки, агент-методист готовит
задания под каждого ученика, преподаватель одобряет, агент-тьютор ведёт ученика вопросами и проверяет результат
командами в его контейнере.

- Дизайн (утверждён 2026-10-31): `docs/superpowers/specs/2026-10-30-edu-trainer-design.md`
- План очереди 1: `docs/superpowers/plans/2026-10-31-edu-trainer-queue1.md`
- Основа: `../DocOps-Intelligence` — переносим **модулями** (учётки, шифрование, шлюз LLM, каркас панели, спрайты
  офиса), а не весь проект. Секреты DocOps (`.env`, `.local-panel/secrets.env`) не копировать.

## Стек и команды
Python 3.12 (строго; `pgserver` для тестов — cp312), uv вызывается как `python -m uv`.
- Установка: `python -m uv sync`
- Тесты: `python -m uv run pytest` (Postgres поднимается сам через `pgserver`; тесты с настоящим Docker —
  `pytest -m docker`, только на сервере)
- Миграции: `python -m uv run alembic upgrade head` (URL из `TRAINER_DATABASE_URL`)
- API: `python -m uv run uvicorn apps.api.main:app --reload`
- Панель: `cd admin && npm run dev` (прокси `/api/*` → `TRAINER_API_URL`); проверки — `npm run typecheck && npm test && npm run build`

## Конвенции
- Пакет `trainer`, env-префикс `TRAINER_`. SQL — `text()` как в DocOps.
- Роли: `teacher` и `student`. Ученик никогда не видит ключи LLM, настройки агентов, чужие задания/комнаты/песочницы,
  задания `draft` и проверочные команды (`checks`).
- Задание `done` — только если прошли **все** проверочные команды.
- Ключи LLM — только через `SecretBox` (AES-GCM), наружу — только «задан/не задан».
